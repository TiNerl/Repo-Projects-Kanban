# (Não é) Meu Primeiro Projeto

Um projeto focado na revisão geral do Markdown (criar, revisar e organizar arquivos Markdown).

</div>

## Sobre

O **Meu primeiro projeto** reúne aprendizados essenciais para trabalhar com Markdown
em um único lugar: modelos, exemplos de sintaxe e uma estrutura simples para
documentar projetos.

## Recursos

- Criar README.md a partir de um modelo;
- Consultar a sintaxe mais utilizada do Markdown;
- Organizar tarefas com um quadro Kanban;
- Padronizar títulos, listas, links, tabelas e checklists;
- Facilitar a documentação de projetos acadêmicos e profissionais.

## Kanban

| Backlog | Em andamento | Concluído |
| --- | --- | --- |
| Definir requisitos | Implementar ferramenta | Criar documentação |
| Revisar funcionalidades | Escrever testes | Publicar versão |

## Guia rápido de Markdown

### Títulos e ênfase

```markdown
# Título principal
## Subtítulo
**negrito**
*itálico*
`código inline`
```

### Listas

```markdown
- Item 1
- Item 2

1. Primeiro passo
2. Segundo passo
```

### Links e imagens

```markdown
[Nome do link](https://exemplo.com)
![Texto alternativo](caminho/para/imagem.png)
```

### Tabela

```markdown
| Campo | Descrição |
| --- | --- |
| Nome | Nome do projeto |
| Status | Em andamento |
```

### Checklist

```markdown
- [x] Tarefa concluída
- [ ] Tarefa pendente
```

## Modelo de projeto

```markdown
# Nome do projeto

## Descrição
Explique brevemente o objetivo do projeto.

## Tecnologias
- Tecnologia 1
- Tecnologia 2

## Como executar
1. Clone o repositório.
2. Instale as dependências.
3. Execute o projeto.

## Autores
- Nome do autor
```

## Contribuição

1. Crie uma branch para sua alteração.
2. Faça commits claros e objetivos.
3. Abra um pull request descrevendo a contribuição.
